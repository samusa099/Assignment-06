## 📌 Overview

A responsive multipage extension of the Quick business website, built with HTML5, custom CSS, responsive media queries, and Google Fonts.

The repository is organised as a self-contained project that can be downloaded, reviewed, and run locally with minimal setup.

---

## ✨ Key Features

- ✅ Responsive header and navigation
- ✅ Dedicated Overview, Landings, Pages, Apps, and Docs pages
- ✅ Hero section for an online-business concept
- ✅ Separate responsive stylesheet
- ✅ Consistent shared branding across pages

---

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure and semantic content |
| **CSS3** | Layout, typography, responsiveness, and visual styling |
| **Responsive Design** | Device-specific layout adaptation |
| **Google Fonts** | Project typography |

## 🚀 Run Locally

```bash
git clone https://github.com/samusa099/Assignment-06.git
cd Assignment-06
```

Open `index.html` directly in a modern browser, or use the **Live Server** extension in Visual Studio Code for automatic refresh.
