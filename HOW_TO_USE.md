# 📘 How, Where & Why to Use This Project

## Project
**Quick Multipage Website — Responsive CSS Practice**

## Why Use It

This repository extends a simple landing page into a multipage website and is useful for learning shared navigation, consistent branding, responsive CSS, page-to-page linking, and reusable layout patterns.

Use it to:

- Practise multipage HTML architecture
- Learn responsive media queries
- Maintain consistent headers and footers
- Review relative file paths between pages
- Build portfolio evidence for responsive front-end skills

## Where It Can Be Used

- Front-end coursework and assignments
- Responsive-design practice
- Small business website prototypes
- Multipage navigation demonstrations
- Beginner portfolio projects

## How to Use It

```bash
git clone https://github.com/samusa099/Assignment-06.git
cd Assignment-06
```

Open `index.html` or run the folder with **VS Code Live Server**.

### Page Map

| Page | Intended Role |
|---|---|
| `index.html` | Main overview and hero page |
| `landings.html` | Landing-page examples or content |
| `Pages.html` | General pages section |
| `apps.html` | Application-related section |
| `docs.html` | Documentation-related section |

### Customisation Steps

1. Update shared navigation links on every page.
2. Replace text and images with a real project concept.
3. Edit global rules in `css/style.css`.
4. Adjust breakpoints in `css/responsive.css`.
5. Test every page and link on desktop, tablet, and mobile.

## File Guide

| File or Folder | Purpose |
|---|---|
| HTML pages | Individual website views |
| `css/style.css` | Main layout and design rules |
| `css/responsive.css` | Mobile and tablet adaptations |
| `images/` | Logos and page illustrations |
| `README.md` | Project overview |
| `HOW_TO_USE.md` | Detailed usage and extension guide |

## Recommended Workflow

1. Verify all existing links.
2. Create shared naming conventions.
3. Update content consistently across pages.
4. Test responsive navigation.
5. Remove duplicated styles where possible.
6. Validate HTML before deployment.

## Suitable Practice Tasks

- Add an active navigation state
- Make the menu mobile-friendly
- Convert repeated markup into templates
- Add a contact page and form
- Improve accessibility and semantic structure
- Deploy with GitHub Pages

## Limitations

- Static pages only
- No shared templating engine
- Repeated navigation must be maintained manually
- No backend or application data
